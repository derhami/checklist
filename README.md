# 📋 مرجع تخصصی چک‌لیست‌های طراحی UX و محصول (Persian UX Checklist)

![چک‌لیست طراحی UX](https://raw.githubusercontent.com/derhami/checklist/main/public/favicon.svg)

> **جامع‌ترین و استانداردترین مرجع فارسی چک‌لیست‌های تخصصی تجربه کاربری (UX)، رابط کاربری (UI)، دسترسی‌پذیری (WCAG) و دیزاین سیستم به همراه ابزارهای سنجش تعاملی.**

---

## 🌟 ویژگی‌های کلیدی پروژه

- **📚 بیش از ۶۹ چک‌لیست تخصصی:** شامل کامل‌ترین استانداردهای طراحی برای انواع وب‌سایت‌ها، کامپوننت‌های رابط کاربر (دکمه، فرم، مودال، جدول و...)، جریان‌های کاربری (ثبت‌نام، پرداخت، بارگذاری فایل) و هویت برند.
- **⚡ ارزیابی زنده و ذخیره‌سازی خودکار:** ذخیره‌سازی درصد پیشرفت و آیتم‌های بررسی‌شده به‌صورت کاملاً آفلاین و ایمن در `localStorage` مرورگر بدون نیاز به ثبت‌نام.
- **📐 ابزارهای تعاملی طراحی در کتابچه راهنما:**
  - **سنجش کنتراست زنده (WCAG Contrast Checker):** ارزیابی خوانایی رنگ متن و پس‌زمینه بر اساس استانداردهای WCAG 2.1 با سطوح AA و AAA.
  - **محاسبه‌گر مقیاس تایپوگرافی (Type Scale Generator):** ایجاد نسبت‌های ریاضی گام‌بندی تیترها بر اساس نسبت‌های استانداردی مثل Major Third و Perfect Fourth.
- **🎨 کپی آماده برای فیگما و مارک‌داون:** قابلیت کپی مستقیم چک‌لیست‌ها با فرمت Markdown جهت استفاده در مستندات پروژه، Figma، Notion و Jira.
- **🔍 جستجوی هوشمند فارسی و انگلیسی:** موتور جستجوی قدرتمند با پشتیبانی از حروف فارسی و عربی (ی/ک)، کوئری‌های چندکلمه‌ای و کلمات کلیدی انگلیسی.
- **📑 حالت چاپ اختصاصی (Print Mode):** بهینه‌سازی شده برای خروجی PDF و پرینت فیزیکی بدون المان‌های اضافی رابط کاربری.
- **📱 کاملاً واکنش‌گرا (Responsive):** بهینه‌سازی دقیق تمامی بخش‌ها برای نمایش بدون نقص در موبایل، تبلت و دسکتاپ.
- **🔍 سئو کامل و بهینه‌سازی موتورهای جستجو:**
  - تگ‌های OpenGraph و Twitter Cards اختصاصی
  - پشتیبانی از داده‌های ساختاریافته (JSON-LD ItemList Schema)
  - نقشه سایت خودکار (`sitemap.xml`) برای تمامی ۶۹+ صفحه چک‌لیست
  - فایل `robots.txt` و `site.webmanifest` جهت قابلیت نصب PWA

## 🏗️ معماری و تکنولوژی‌ها

این پروژه با بالاترین استانداردهای توسعه فرانت‌اند پیاده‌سازی شده است:

## 🔍 سئو و موتورهای جستجو

پروژه شامل ساختار کامل SEO جهت رتبه‌گیری عالی در گوگل می‌باشد:
- **تگ‌های Dynamic SEO:** عنوان و توضیحات اختصاصی برای هر چک‌لیست از طریق کامپوننت `<SEO />`.
- **JSON-LD Schema:** تعریف استانداردهای `ItemList` و `WebSite` برای نمایش اسنیپت‌های غنی (Rich Snippets).
- **Sitemap Generator:** تولید کامل نقشه سایت برای تمام مسیرها جهت ایندکس سریع توسط Googlebot.
